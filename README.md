# 📝 To-Do List App (Vanilla JavaScript)

یک اپلیکیشن ساده، زیبا و کاربردی برای مدیریت کارهای روزانه  
ساخته‌شده با **HTML, CSS و JavaScript خالص (Vanilla JS)**

---

## ✨ ویژگی‌ها (Features)

- ➕ افزودن تسک جدید
- ✏️ ویرایش تسک با کلیک روی آن
- ❌ حذف تسک
- 🚫 لغو عملیات ویرایش (Cancel)
- 🔍 فیلتر کردن تسک‌ها
- 🗑️ حذف همه تسک‌ها
- 💾 ذخیره اطلاعات در `localStorage`
- 🔁 Drag & Drop برای تغییر ترتیب تسک‌ها
- 🎨 رابط کاربری شاداب و کاربرپسند
- 📱 طراحی ساده و ریسپانسیو

---

## 🧠 مفاهیم استفاده‌شده

- Event Delegation
- DOM Manipulation
- Local Storage
- HTML5 Drag & Drop API
- CSS Transitions & Hover Effects
